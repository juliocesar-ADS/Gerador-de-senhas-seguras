# 🔐 Gerador de Senhas Seguras

Um aplicativo para gerar senhas seguras com interface gráfica usando Python e Tkinter.

## ✨ Funcionalidades

- ✅ Gerar senhas aleatórias e seguras
- ✅ Customização de comprimento
- ✅ Interface com Tkinter
- ✅ Copiar para clipboard

## 📋 Requisitos

- Python 3.7+
- tkinter

## 🚀 Como Usar

```bash
git clone https://github.com/juliocesar-ADS/Gerador-de-senhas-seguras.git
cd Gerador-de-senhas-seguras
python Password.py
```
